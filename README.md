# Анализ структуры клиентской базы интернет-магазина

Веб-приложение для оператора e-commerce/CRM, которое импортирует Excel-файл с клиентской базой, рассчитывает структуру клиентов, строит KPI, диаграммы, карту регионов и позволяет сегментировать данные.

## Что умеет приложение

- Импортирует Excel-файлы `.xlsx`.
- Проверяет структуру и значения загруженных данных.
- Показывает понятные уведомления об успешной загрузке или ошибках.
- Рассчитывает частоты и доли клиентов по полу, регионам и возрастным группам.
- Рассчитывает описательные статистики: средний доход, средний расход, медиану, моду, среднее число заказов.
- Визуализирует данные через столбчатые диаграммы, круговую диаграмму, график регистраций и интерактивную карту.
- Позволяет сегментировать клиентов по возрасту, полу, региону, количеству заказов, среднему чеку и дате регистрации.
- Экспортирует полный аналитический отчет в CSV.
- Позволяет скачать Excel-шаблон с нужными колонками.

## Структура Excel-файла

Файл должен содержать такие колонки:

| Колонка | Пример |
| --- | --- |
| Возраст | `32` |
| Пол | `Ж`, `М`, `Женский`, `Мужской` |
| Регион | `Москва` |
| Дата регистрации | `15.02.2026` или `2026-02-15` |
| Количество заказов | `6` |
| Средний чек | `7200` |

В репозиторий добавлен пример файла: `client_base_ru_text_dates.xlsx`.

## Как запустить

### 1. Установить Node.js

Нужен Node.js версии `20` или выше.

Проверка:

```powershell
node -v
```

### 2. Перейти в папку проекта

```powershell
cd "C:\path\to\project"
```

### 3. Установить зависимости

```powershell
npm install
```

Приложение может работать и без установки зависимостей в файловом режиме, но `npm install` нужен для PostgreSQL-режима через пакет `pg`.

### 4. Запустить сервер

```powershell
npm start
```

Или напрямую:

```powershell
node server.js
```

### 5. Открыть приложение

Откройте в браузере:

```text
http://localhost:4173
```

## Как работать с приложением

1. Откройте страницу приложения.
2. В блоке `Импорт данных` нажмите на область `Загрузить Excel-файл`.
3. Выберите `.xlsx` файл с клиентской базой.
4. Если файл корректный, появится уведомление об успешной загрузке, а dashboard автоматически обновится.
5. Если файл содержит ошибки, откройте блок `Контроль качества`: там будут указаны строки и причины ошибок.
6. Используйте блок `Сегментация`, чтобы фильтровать клиентов по нужным критериям.
7. Изучайте KPI, описательную статистику, диаграммы, таблицу регионов и карту.
8. Нажмите `Экспорт CSV`, чтобы скачать полный отчет.
9. Нажмите `Скачать шаблон Excel`, если нужно получить файл с правильной структурой колонок.

## Фильтры

Числовые фильтры используют правило:

- `0` означает, что ограничение не применяется;
- любое число больше `0` включает соответствующий фильтр.

Например:

- `Заказы до = 0` значит “не ограничивать по заказам”;
- `Заказы до = 30` значит “показать клиентов с количеством заказов до 30”.

## Хранение данных

По умолчанию данные сохраняются в локальный файл:

```text
data/clients.json
```

При первом запуске файл создается пустым. Данные появятся после загрузки Excel-файла через интерфейс.

## PostgreSQL

Для промышленного варианта можно использовать PostgreSQL.

1. Создайте базу данных.
2. Примените схему:

```sql
database/schema.sql
```

3. Укажите переменную окружения:

```powershell
$env:DATABASE_URL="postgres://user:password@localhost:5432/database"
```

4. Установите зависимости:

```powershell
npm install
```

5. Запустите сервер:

```powershell
npm start
```

Если `DATABASE_URL` задан, backend автоматически использует PostgreSQL. Если переменная не задана, используется локальное файловое хранилище.

## Основные файлы проекта

- `server.js` - backend, API, хранение данных, валидация, расчеты аналитики.
- `public/index.html` - HTML-страница приложения.
- `public/app.js` - клиентская логика dashboard.
- `public/styles.css` - оформление интерфейса.
- `public/favicon.svg` - иконка приложения.
- `database/schema.sql` - схема PostgreSQL.
- `client_base_ru_text_dates.xlsx` - пример Excel-файла.
- `data/clients.json` - локальное хранилище загруженных данных.
